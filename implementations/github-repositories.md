# GitHub Implementations

## SelfCheckGPT

**Repository:** [potsawee/selfcheckgpt](https://github.com/potsawee/selfcheckgpt)  
**What it implements:** Sampling-based, zero-resource hallucination detection for LLM-generated text.  
**Why it is relevant:** It can detect instability across repeated model outputs, which is closely related to citation drift.

## FActScore

**Repository:** [shmsw25/FActScore](https://github.com/shmsw25/FActScore)  
**What it implements:** Fine-grained factuality evaluation by checking atomic claims against external evidence.  
**Why it is relevant:** It supports claim-level verification for AI-generated literature summaries.

## TRUE

**Repository:** [google-research/true](https://github.com/google-research/true)  
**What it implements:** A benchmark and evaluation framework for factual consistency in natural-language generation.  
**Why it is relevant:** It helps assess whether generated claims are faithful to source information.

## SummEval

**Repository:** [Yale-LILY/SummEval](https://github.com/Yale-LILY/SummEval)  
**What it implements:** A benchmark toolkit for evaluating machine-generated summaries using human judgments and automatic metrics.  
**Why it is relevant:** It supports evaluation of factual consistency in generated summaries.

## Hugging Face Transformers

**Repository:** [huggingface/transformers](https://github.com/huggingface/transformers)  
**What it implements:** Open-source pretrained transformer models and NLP pipelines.  
**Why it is relevant:** It can be used to build custom citation verification, retrieval, and hallucination-detection systems.
