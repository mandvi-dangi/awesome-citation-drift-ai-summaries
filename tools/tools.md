# Tools and Libraries

## Crossref REST API

**Purpose:** Searches DOI records and scholarly publication metadata.  
**Use in this topic:** Verifies titles, authors, years, journals, and DOI details of AI-generated citations.  
[Official documentation](https://api.crossref.org/)

## Semantic Scholar Academic Graph API

**Purpose:** Provides scholarly-paper metadata, citation data, authors, and abstracts.  
**Use in this topic:** Helps verify whether an AI-generated citation refers to a real publication.  
[Official documentation](https://api.semanticscholar.org/)

## OpenAlex API

**Purpose:** Provides open scholarly metadata about research works, authors, venues, and citations.  
**Use in this topic:** Supports large-scale checking of publication and author information.  
[Official documentation](https://docs.openalex.org/)

## Hugging Face Transformers

**Purpose:** A library for using pretrained language models for natural-language-processing tasks.  
**Use in this topic:** Can be used to build hallucination-detection, classification, and claim-verification systems.  
[Official repository](https://github.com/huggingface/transformers)

## Sentence Transformers

**Purpose:** Produces semantic text embeddings for similarity and retrieval tasks.  
**Use in this topic:** Helps compare AI-generated claims, references, and retrieved scholarly evidence.  
[Official repository](https://github.com/UKPLab/sentence-transformers)
