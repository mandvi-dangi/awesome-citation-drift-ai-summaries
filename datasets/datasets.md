# Datasets and Benchmarks

## FRANK Benchmark

**Source:** NAACL 2021 / ACL Anthology  
**Description:** FRANK is a benchmark for evaluating factual errors in abstractive text summarization. It contains human annotations for different factual-error types.  
**Use in this topic:** Useful for testing whether AI-generated literature summaries contain unsupported or incorrect statements.  
[Official paper and resource](https://aclanthology.org/2021.naacl-main.383/)

## TRUE Benchmark

**Source:** Google Research / NAACL 2022  
**Description:** TRUE is a collection of factual-consistency datasets from several natural-language-generation tasks.  
**Use in this topic:** Useful for evaluating factual-consistency metrics used to detect hallucinated claims.  
[Official project repository](https://github.com/google-research/true)

## SummEval Dataset

**Source:** Yale Language, Information, and Learning Lab / TACL 2021  
**Description:** SummEval provides machine-generated summaries and expert or crowd-sourced human ratings for consistency, relevance, fluency, and coherence.  
**Use in this topic:** Useful for studying and comparing summary-evaluation methods.  
[Official project repository](https://github.com/Yale-LILY/SummEval)
